# Project GRP v1

## Dataset Contract

`prepare_grp_v1.py` found 2,000 independent native hanchans outside the formal F/G corpus. The split is:

| Split | Hanchans |
| --- | ---: |
| train | 1,600 |
| validation | 200 |
| holdout | 200 |

The audit passed with zero malformed logs, zero canonical duplicates, zero seed/key overlaps, and zero canonical overlap with the formal 6,000-hanchan F/G corpus. The source is historical native evaluation/league data retained in the workspace; it is not copied into the GRP directory.

## Model And Runner

`run_grp_training.py` uses the upstream `GRP(hidden_size=64, num_layers=2)` and AdamW learning rate `1e-5`, but adds finite target steps, deterministic train/validation streams, resume cursors, RNG state, checkpoint archives, and project/repository hashes.

The runner reports 24-class NLL, top-1 accuracy, Brier score, expected-Pt MAE, marginal calibration proxy, and phase-group metrics. The best checkpoint is selected by validation NLL; holdout is evaluation-only.

## Checkpoint Result

`keqing_grp_v1_best.pth` reached step 10,000. Validation NLL improved monotonically across the saved checkpoints:

| Step | Validation NLL | Top-1 | Brier | Expected-Pt MAE |
| ---: | ---: | ---: | ---: | ---: |
| 2,000 | 3.1053 | 9.65% | 0.9520 | 1.9422 |
| 4,000 | 2.9065 | 11.86% | 0.9322 | 1.7647 |
| 6,000 | 2.7645 | 13.89% | 0.9153 | 1.6459 |
| 8,000 | 2.6996 | 15.42% | 0.9057 | 1.6000 |
| 10,000 | 2.6700 | 15.89% | 0.9003 | 1.5781 |

At step 10,000, the independent holdout reported NLL `2.6145`, top-1 `20.53%`, Brier `0.8867`, and expected-Pt MAE `1.5434`. Both validation and holdout are materially below the uniform 24-class NLL baseline `log(24) = 3.1781`.

## Reward Preflight

Using the frozen step-10,000 checkpoint on the formal 6,000-hanchan F/G corpus produced 62,695 decision samples. Reward mean was `0.0215`, standard deviation `0.5262`, and nonzero rate `100%`. Absolute delta-Pt quantiles were p50 `0.2054`, p95 `1.1165`, p99 `2.0030`, max `4.7365`; per-hanchan sum(abs(delta-Pt)) p50 `3.3580`, p95 `5.8811`, p99 `7.1484`, max `9.3753`. No zero-reward collapse or extreme oscillation gate was triggered.

This checkpoint is frozen for the first reward A/B. It is not retrained per DQN seed and is not used as an action imitation label.
