## 背景与动机

`K0_REPR_AUDIT_2026_08` 回答的是：

> M0 与 D1/D2/D3 在 `Brain(obs)` 的**状态表示**上是否明显不同？

机器结论是“不明显”。

但实际训练不是 `state → final_rank`。当前 `behavior_action_mc` 的 objective 明确是：

```text
value loss:
Q(s, a_behavior) → final_rank_mc

+

CQL:
logsumexp(Q_legal) - Q(s, a_behavior)
```

因此：

- `behavior_action` 决定 value target 被贴在哪个 action 上；
- 同一个 behavior action 又决定 CQL 要把哪个 action 相对其他合法动作往上推；
- state distribution 相同，不推出 training signal 相同。

举例：同样相似的状态下，M0 的 behavior action 是 `3m`、D1 是 `4m`，即使 `phi` 几乎一样，Q table 的监督方向也不同。

历史线索：2026-07 Objective Learnability Audit 的小 batch 诊断曾看到：

```text
M0:
weighted DQN/CQL backbone cosine ≈ +0.72

S0:
weighted DQN/CQL backbone cosine ≈ -0.34
```

该诊断只是小 batch，不能作为结论。本审计将其升级为正式、大样本、预注册的机制问题。

## 核心研究问题

> 当 K0 看到相似的状态时，M0 与 D1/D2/D3 是否提供了不同的 behavior-action support，并因此产生不同的 objective gradient？

本审计不训练、不生成、不创建 experiment ID，只对已有权威产物和已有 loader 做只读分析。

## 第一组：Local Action Support

在已有 K0 latent neighborhood 上，对每个 canonical row 计算：

1. **behavior agreement**（descriptive only）：
   `a_behavior == argmax K0 Q`。
2. **local action entropy**：
   对 query 的 latent kNN，统计 raw 46 action ID 的经验分布：
   `H(A | local K0-state neighborhood)`，`effective_action_count = exp(H)`。
   - raw action ID 是主指标；
   - action-kind 只做解释，不进入主投票。
3. **mutually-legal alternative support**：
   对 query action `a` 与 neighbor action `b`，仅当：
   - `a` 在 neighbor 中合法；
   - `b` 在 query 中合法；
   才把 `(a,b)` 记为真正可比较的局部 alternative。
   指标：
   - `switchable_alternative_rate`
   - `local_distinct_mutually_legal_actions`

本组回答：

> 数据是否真的给模型展示了“类似局面下，还有别的合法选择”。

## 第二组：直接计算 Q-gradient（row-level，解析）

不需要对几百万参数做 autograd；先在 46-d Q-output gradient 上做全量 72k 行。

对每一行：

```text
q = K0 DQN(phi, legal_mask)
a = behavior_action
y = final_rank_mc
λ = CQL weight = 5
```

当前 objective 的 row-level Q-output gradient 解析为：

```text
g_value = (Q_a - y) · one_hot(a)

g_cql   = λ · (softmax(Q_legal) - one_hot(a))

g_total = g_value + g_cql
```

batch mean 只是全局 scale；比较 row geometry 时不影响方向。

每个 route 至少报告：

```text
||g_value||
||g_cql||
||g_total||

cos(g_value, g_cql)

behavior-action push magnitude

common-Q component
centered preference component

greedy action flip pressure
top-alternative suppression pressure
```

其中 `cos(g_value, g_cql)` 是把旧的小 batch 线索升级为大样本机制审计的核心指标之一。

## 第三组：比较 gradient distribution，而不是几个均值

沿用已验证的 natural control：

```text
VIEW_BASELINE = distance(D1, D2)
```

然后：

```text
Δ1 = distance(M0, D1) - distance(D1, D2)
Δ3 = distance(M0, D3) - distance(D1, D2)
```

但这次 `distance()` 比较的是 state-conditioned action / gradient distribution，而不是 state latent。

推荐四个 metric family：

1. local mutually-legal action support
2. `g_total` direction distribution
3. value-vs-CQL conflict distribution
4. centered preference-gradient magnitude distribution

全部使用 hanchan-cluster bootstrap。不用手工 `phase/rank/shanten` 作为主证据。

## 第四组：Action-level credit（descriptive only，不进入机器投票）

上一阶段 `p_predict = 0.001` 只说明：

> K0 state representation 对最终 rank 有信息。

它没有证明：

> 在这个状态下选择某一个具体 action，`final_rank_mc` 对这个 action 是合理的 credit。

本组看：

```text
H(Y | local state neighborhood)
vs
H(Y | local state neighborhood, action)
```

只在 mutually-legal action support 足够的 neighborhood 中统计；否则 D1 这类近乎 deterministic behavior policy 会因为没有 alternative action 而产生假的“action certainty”。

本组**先 descriptive only，不进入第一版机器投票**。原因是它本质仍是 observational association，不应轻率解释成 action causality。

## 机器结论（建议四态）

```text
state_action_support_signal
objective_gradient_shift_signal
both_signals
inconclusive
```

### `state_action_support_signal`

只有当 M0 相比 D1/D3 存在稳定更丰富的：

```text
mutually-legal local action support
```

且超出 D1↔D2 view baseline，才成立。

这比简单 `greedy agreement M0=89% / D1=99.99%` 强得多；简单 disagreement rate 会被 D2 这类情况误导。

### `objective_gradient_shift_signal`

只有多个 gradient metric family 都显示：

```text
M0↔D1
M0↔D3

显著大于

D1↔D2 baseline
```

才成立。不能根据某一个 `mean gradient cosine` 拍板。

### 组合

```text
support=false, gradient=false → inconclusive
support=true,  gradient=false → state_action_support_signal
support=false, gradient=true  → objective_gradient_shift_signal
support=true,  gradient=true  → both_signals
```

任一 provenance/integrity gate 失败时，不输出上述四态；报告为 `no_verdict_gates_failed` 且 `authoritative=false`。

## 对下一实验的决策边界

- `state_action_support_signal`：
  下一步不叫 coverage augmentation，应转成 **action-support / policy-diversity data design**——研究如何保留 M0 中有价值的 alternative-action supervision，而不是生成更多相似 K0 states。
- `objective_gradient_shift_signal`：
  先不立刻改 reward；进一步确定是 behavior-action label distribution 本身造成 gradient shift，还是 `behavior_action_mc + CQL` 的 coupling 放大 shift。`legal_mean_mc` 已正式 A/B 失败，不能把旧失败方案重新包装再试。
- `both_signals`：
  最可能的故事是：M0 的优势不是 state coverage，而是在相同 state region 中提供不同且有信息量的 action labels，而当前 objective 又强烈依赖 behavior action，因此形成不同训练梯度。这值得做真正 controlled experiment。
- `inconclusive`：
  到这里停止 observational audit；因为已依次审过 raw structured corpus、state latent coverage、state-level credit predictability、state-action training signal。如果四层都不能区分 M0 与失败路线，下一步直接做最小 controlled intervention。
