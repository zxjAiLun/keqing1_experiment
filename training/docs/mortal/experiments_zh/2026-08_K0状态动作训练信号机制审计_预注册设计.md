## 背景与动机

`K0_REPR_AUDIT_2026_08` 回答的是：

> M0 与 D1/D2/D3 在 `Brain(obs)` 的**状态表示**上是否明显不同？

机器结论是“不明显”。

但实际训练不是 `state → final_rank`。当前 `behavior_action_mc` 的 objective 明确是：

```text
value loss:
Q(s, a_behavior) → final_rank_mc

+

CQL:
logsumexp(Q_legal) - Q(s, a_behavior)
```

因此：

- `behavior_action` 决定 value target 被贴在哪个 action 上；
- 同一个 behavior action 又决定 CQL 要把哪个 action 相对其他合法动作往上推；
- state distribution 相同，不推出 training signal 相同。

举例：同样相似的状态下，M0 的 behavior action 是 `3m`、D1 是 `4m`，即使 `phi` 几乎一样，Q table 的监督方向也不同。

历史线索：2026-07 Objective Learnability Audit 的小 batch 诊断曾看到：

```text
M0:
weighted DQN/CQL backbone cosine ≈ +0.72

S0:
weighted DQN/CQL backbone cosine ≈ -0.34
```

该诊断是 **parameter-gradient / backbone 空间**的小样本观察，不是 Q-output 空间的结论。本审计不把它直接改名为 Q-output 大样本升级；它作为第五组 parameter/Adam descriptive diagnostic 的动机。

## 核心研究问题

> 当 K0 看到相似的状态时，M0 与 D1/D2/D3 是否提供了不同的 behavior-action support，并因此产生不同的 objective gradient？

本审计不训练、不生成、不创建 experiment ID，只对已有权威产物和已有 loader 做只读分析。

```text
ANCHORS = 四路 canonical reservoir 的等权 pooled set
        = 72,000 rows
```

```text
N_M0(q)

```

全部：

```text

```

这样比较的是：

> 在同一个 K0 state region 周围，各 route 给了什么 behavior actions。

Bootstrap 时 anchor panel 固定 route-balanced：

```text
M0      independent 6000-hanchan draw
D1/D2   shared underlying-hanchan draw
D3      independent draw
```

同一 replicate 对四个 reference route 使用同一份 anchor weights。

### Support bootstrap：conditional on frozen reference reservoirs

```text
N_M0(q), N_D1(q), N_D2(q), N_D3(q)
在 full frozen 18k reference 上各计算一次并固定。
```

- bootstrap **不重抽 reference**；
- **不改变 top-16 neighbor membership**；
- 不按 reference multiplicity 物理复制或加权改变 neighbor 集合；
- bootstrap 只重新赋予 `ANCHORS` 的 hanchan multiplicity weights：

```text
M0 anchors     → w_M0
D1 anchors     → w_D12
D2 anchors     → 同一个 w_D12
D3 anchors     → w_D3
```

然后这一整套 72k anchor weights **同时用于四个 `S_R`**。

报告必须注明：

> support CI 是 conditional-on-frozen-reference-reservoir 的 anchor-cluster uncertainty，不是 replay-generation population uncertainty。


## 第一组：Local Action Support

### 主指标（machine vote，2/2）

对 anchor `q`：

```text
a_q = anchor behavior action
```

neighbor `j` eligible 当且仅当：

```text
a_q legal in j
AND
a_j legal in q
```

冻结两个主指标：

```text
S1 switchable_rate_R(q)
=
#(eligible neighbor with a_j != a_q) / 16

S2 distinct_alt_R(q)
=
#unique {a_j != a_q | eligible}
```

分母固定 16；**不用 eligible_count 作分母**，避免只有 2 个可比邻居的 neighborhood 虚假得到 100%。

### Route-level aggregation

对每个 route `R`：

```text
S_R = weighted mean over shared anchors
```

对每个 support metric：

```text
view_gap = |S_D1 - S_D2|

delta1 = (S_M0 - S_D1) - view_gap
delta3 = (S_M0 - S_D3) - view_gap
```

### support 投票规则

```text
state_action_support_signal = true
iff

S1: delta1 CI lower > 0 AND delta3 CI lower > 0
AND
S2: delta1 CI lower > 0 AND delta3 CI lower > 0
```

即 **2/2**，运行后不改为 1/2。

### Descriptive only

- raw 46-action entropy：`H(A | local K0-state neighborhood)`，`effective_action_count = exp(H)`；
- behavior agreement：`a_behavior == argmax K0 Q`；
- 这些不进入主投票。

## 第二组：直接计算 Q-gradient（row-level，解析）

不需要对几百万参数做 autograd；先在 46-d Q-output gradient 上做全量 72k 行。

对每一行：

```text
q = K0 DQN(phi, legal_mask)
a = behavior_action
y = final_rank_mc
λ = CQL weight = 5
```

当前 objective 的 row-level Q-output gradient 解析为：

```text
g_value = (Q_a - y) · one_hot(a)

g_cql   = λ · (softmax(Q_legal) - one_hot(a))

g_total = g_value + g_cql
```

batch mean 只是全局 scale；比较 row geometry 时不影响方向。

**概念边界**：这里计算的是 `∂L/∂Q ∈ R^46`，是 pre-Jacobian objective-pressure audit；不是旧 `+0.72 / -0.34` 的 parameter-gradient / backbone cosine 大样本升级。parameter-gradient 延伸只在第五组 microbatch autograd diagnostic 中出现。

## 第三组：三个 gradient family（machine vote，2/3）

所有 gradient family 都使用各 route 自己的 canonical rows 计算 row-level 分布，再用下述 route distance 比较。

### G1 — total Q-gradient direction

```text
g = g_total
ĝ = g / ||g||₂
```

非法 action 坐标固定为 0。

route distance 使用固定 RFF-MMD：

```text
RBF on unit ĝ
D_rff = 2048
pair_seed = 20260822
rff_seed  = 20260823

sigma =
pooled four-route cross-hanchan pair-distance median
```

pair sampling 完全复制上一轮：

```text
65536 pairs / route
```

fallback `sigma = 0.1`。

RFF-MMD estimator 与上一轮表示审计相同：

```text
omega ~ N(0, (1/sigma²) I)
b ~ Uniform(0, 2π)
psi(x) = sqrt(2/D_rff) * cos(omega·x + b)
MMD² ≈ ||mean(psi(A)) - mean(psi(B))||²
```

其中 `x` 是单位化的 `ĝ`；非法 action 坐标已经置 0。

### G2 — value/CQL conflict

```text
c = cos(g_value, g_cql)
```

```text
c > 0  alignment
c < 0  conflict
```

route distance：

```text
1D Wasserstein(c_A, c_B)
```

`1D Wasserstein` 使用本文件 Bootstrap 协议中定义的 weighted 1-Wasserstein；full-sample 时自然退化为等权 empirical Wasserstein。

同时 descriptive 报：

```text
conflict_rate = P(c < 0)
```

### G3 — centered preference pressure

对每行合法 action 集 `L`：

```text
u = legal_mask / sqrt(|L|)

g_common   = <g_total,u> u
g_centered = g_total - g_common
```

主变量：

```text
m_centered = ||g_centered||₂
```

route distance：

```text
1D Wasserstein(m_centered_A, m_centered_B)
```

同样使用 weighted 1-Wasserstein（见 Bootstrap 协议）；full-sample 时自然退化为等权 empirical Wasserstein。

Implementation test 必须锁住 sanity check：

```text
sum(g_cql over legal actions) ≈ 0
```

### Zero-gradient 边界

冻结：

```text
GRAD_EPS = 1e-12
```

G1：

```text
if ||g_total|| > GRAD_EPS:
    ĝ = g_total / ||g_total||
else:
    ĝ = zero vector
```

零梯度行**继续进入 G1**，并额外 descriptive 报：

```text
zero_total_gradient_rate
```

G2：

```text
defined iff
||g_value|| > GRAD_EPS
AND
||g_cql|| > GRAD_EPS
```

只有 defined rows 进入 cosine distribution：

```text
c = dot(g_value, g_cql) /
    (||g_value|| ||g_cql||)
```

每 route 必须报告：

```text
cosine_defined_rows
cosine_defined_rate
```

不得运行后因为 defined rate 看起来不好再换处理规则。

G3 无需排除；`m_centered = 0` 是合法值。

另外 descriptive：

```text
alt_suppression
```

仅在 `legal_count >= 2` 时定义，其余记 NA，并报告 defined rate。

### Gradient 投票规则

对每个 family：

```text
delta1_m = d(M0,D1) - d(D1,D2)
delta3_m = d(M0,D3) - d(D1,D2)
```

```text
family vote true
iff
delta1 CI lower > 0
AND
delta3 CI lower > 0
```

冻结：

```text
objective_gradient_shift_signal = true
iff >= 2 / 3 gradient families vote true
```

报告措辞建议使用更精确的：

```text
objective_q_gradient_shift_signal
```

若保留四态名 `objective_gradient_shift_signal`，必须在报告中注明：

> signal 指 `dL/dQ` distribution shift，不等价于 parameter-gradient / optimizer shift。

### Descriptive gradient 指标（不进入投票）

```text
behavior_push
= -g_total[a_behavior]
```

正值表示 gradient descent 倾向抬高 behavior Q。

```text
a_greedy = argmax Qlegal

flip_pressure
= -(g_total[a_behavior] - g_total[a_greedy])
```

表示 infinitesimal SGD 下 `Q_behavior - Q_greedy` 的变化方向。

```text
a_alt =
argmax Q among legal actions excluding a_behavior

alt_suppression
= g_total[a_alt]
```

正值意味着 descent 倾向压低该 alternative。

## Bootstrap 协议（machine vote 统一）

```text
B = 1000
seed = 20260821
CI = percentile 2.5 / 97.5
```

- cluster 单位是 `canonical_hanchan_hash`，不是 row；
- D1/D2 必须 paired：同一 replicate 使用 shared hanchan draw `w_D12`；
- M0 使用独立 `w_M0`；
- D3 使用独立 `w_D3`；
- 同一 replicate 中，`d(M0,D1)` 与 `d(D1,D2)` 里的 D1 使用同一份 `w_D12`；
- support 的 anchor weights 也由同一 replicate 的 `w_M0 / w_D12 / w_D3` 构成，并对四个 reference route 使用同一份 anchor weights。

### Weighted 1-Wasserstein（G2/G3）

```text
full-sample:
  每 row 权重 = 1

bootstrap replicate:
  row weight =
  该 row 所属 hanchan 在本 replicate 中的 multiplicity
```

weighted 1-Wasserstein 定义为：

```text
∫ |F_A(x) - F_B(x)| dx
```

实现必须使用**精确 weighted empirical CDF**，不要依赖 library 默认行为：

```text
1. 按 scalar value 排序
2. 同值权重相加
3. 各自权重归一化为 sum=1
4. 合并两分布全部 breakpoints
5. 在相邻 breakpoint 区间积分 |CDF_A - CDF_B|
```

full-sample 时自然退化成普通 empirical Wasserstein。

## 第四组：Action-level credit（descriptive only）

上一阶段 `p_predict = 0.001` 只说明：

> K0 state representation 对最终 rank 有信息。

它没有证明：

> 在这个状态下选择某一个具体 action，`final_rank_mc` 对这个 action 是合理的 credit。

本组冻结：

```text
k_credit = 64
same-hanchan exclusion
```

query eligible 当且仅当：

```text
至少 2 个 mutually-legal behavior-action groups
且每组 >= 4 neighbors
```

指标：

```text
H_state =
entropy(target among eligible neighbors)

H_state_action =
Σ_a P(a) H(target | a)

action_information_gain =
H_state - H_state_action
```

报告：

```text
eligible_query_fraction
H_state
H_state_action
information_gain
```

本组 **descriptive only，不进入机器投票**。不能根据跑出来 eligible 太少再把 `4` 改成 `2`。

固定 deterministic microbatch：

```text
32 rows × 32 batches / route
hanchan-balanced
seed = 20260824
```

必须保存 sampled row identities SHA。

Parameter groups：

```text
brain

aux
brain+dqn total
```

```text
cos(g_current, m_legacy)

```

## 对下一实验的决策边界

- `state_action_support_signal`：
  下一步不叫 coverage augmentation，应转成 **action-support / policy-diversity data design**——研究如何保留 M0 中有价值的 alternative-action supervision，而不是生成更多相似 K0 states。
- `objective_gradient_shift_signal`：
  先不立刻改 reward；进一步确定是 behavior-action label distribution 本身造成 gradient shift，还是 `behavior_action_mc + CQL` 的 coupling 放大 shift。`legal_mean_mc` 已正式 A/B 失败，不能把旧失败方案重新包装再试。
- `both_signals`：
  最可能的故事是：M0 的优势不是 state coverage，而是在相同 state region 中提供不同且有信息量的 action labels，而当前 objective 又强烈依赖 behavior action，因此形成不同训练梯度。这值得做真正 controlled experiment。
- `inconclusive`：
  到这里停止 observational audit；因为已依次审过 raw structured corpus、state latent coverage、state-level credit predictability、state-action training signal。如果四层都不能区分 M0 与失败路线，下一步直接做最小 controlled intervention。
