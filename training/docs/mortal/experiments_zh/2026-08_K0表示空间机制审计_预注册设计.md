## 固定降维与存储

- `phi_dim = 1024`。
- 固定随机投影 `P ∈ R^{256×1024}`：`torch.Generator(seed=20260815)`，标准正态生成后每行 L2 归一化；保存矩阵与 SHA-256。
- 存储前对投影 `z = P @ phi` 做 L2 归一化；距离默认使用 `cosine_distance = 1 - dot(z_a, z_b)`。
- 额外保存 `phi_l2_norm = ||phi||₂`。它只做 descriptive diagnostic，不进入四态投票。
- canonical reservoir：每 route 每 hanchan 固定取 3 行，行号 `idx_j = floor((j + 0.5) * n / 3)`，`j=0,1,2`，`n` 为该 hanchan loader row 数。共 `4×6000×3=72000` 条。Gate B 要求所有 canonical hanchan `n >= 3`；任何 `n < 3` 直接 gate B FAIL，不发明 fallback。
- 每个 reservoir 行保存：`route, file_index, row_index, canonical_hanchan_hash, perspective_label, target, phi_l2_norm, z`；D3 额外保存 event category（普通行记 `ordinary`）。
- `canonical_hanchan_hash` 使用 v2 gate-E 的 `_canonical_log_hash(_read_log(path))`。D1 与 D2 共享同一 underlying hanchan hash 体系。
- D3 event row 全集：对 v2 gate-F 的 151,282 个 exactly-once mapped rows，保存 `category ∈ {explored, hash_rejected, budget_exhausted}`、`file_index, row_index, canonical_hanchan_hash, target, phi_l2_norm, z`。普通 D3 行使用 canonical reservoir。
- D3 exploration downstream：对每个 `explored` 行，保存同 hanchan 内紧接着的最多 8 条 loader row 的 `z`、`target` 与 row 身份字段；不足 8 条按实际条数。下游样本只做描述性密度/距离，不参与四态投票。
- hanchan-exposure-weighted canonical proxy：每 route × seed 从 v2 `training_exposure.json` 的 `consumed_per_file` 权重做固定 seed 的加权采样，N=18000。它**不是 exact row-level training exposure**，只用于第四组描述性比较，不参与四态投票。

## 冻结距离指标

四个 metric families 均先在固定投影、L2 归一化空间计算。所有 kNN / missing-mass neighbor search 都排除 `self` 以及相同 `canonical_hanchan_hash` 的行。

1. `sliced_wasserstein`：256 个固定投影方向，`direction_seed=20260816`；每方向按 4096 个均匀分位数计算 1-Wasserstein。
2. `rbf_mmd`：
   - kernel：`k(x,y) = exp(-||x - y||² / (2 * sigma²))`，其中 `x,y` 是 L2 归一化后的 `z`。
   - estimator：固定 Random Fourier Features，`D_rff = 2048`，`rff_seed = 20260820`；`omega ~ N(0, (1/sigma²) I)`，`b ~ Uniform(0, 2π)`，特征 `psi(x) = sqrt(2/D_rff) * cos(omega·x + b)`，`MMD² ≈ ||mean(psi(A)) - mean(psi(B))||²`。
   - `sigma`：每 route 用 `pair_seed = 20260819` 确定性取 65536 个 **cross-hanchan unordered pairs**，四路共 262144 个 `||z_i - z_j||₂`；`sigma = median(所有 pair distances)`。`median == 0` 时 fallback `sigma = 0.1`。`sigma` 必须在 bootstrap 与最终判定前写入报告并冻结。
3. `cross_knn_distance`：`k=16`；同时报告 `A→B` 与 `B→A`，投票使用两者均值。D1↔D2 比较中，同 underlying hanchan 的邻域排除规则同样生效。
4. `latent_missing_mass`：
   - 对 route A 的每条 reservoir 行，若 B 中 `k=16` 最近邻平均距离大于 B 自身 `k=16` 最近邻距离的 95th percentile，则记为 missing；`missing_mass(A→B)=missing_count/|A|`。
   - 4-family vote 使用的 symmetric distance 为：
     `d_missing(A,B) = 0.5 * [missing_mass(A→B) + missing_mass(B→A)]`。
   - M0-specific support gate 使用 directional difference：
     `missing_mass(M0→D) - missing_mass(D→M0)`。

## 冻结 bootstrap 协议

- `B = 1000`，`bootstrap_seed = 20260817`。
- cluster 单位是 `canonical_hanchan_hash`，不是 row。每次 replicate 从 6000 个 hanchan 中 **with replacement** 抽 6000 个，得到 hanchan multiplicity weight。
- **D1/D2 必须 paired**：每个 replicate 中，D1 和 D2 使用同一份 shared hanchan draw `w_D12`；M0 使用独立 draw `w_M0`；D3 使用独立 draw `w_D3`。同一 replicate 中 `d(M0,D1)` 与 `d(D1,D2)` 里的 D1 必须使用同一份 `w_D12`。
- SW / RFF-MMD：
  - bootstrap 分布 = 以 hanchan multiplicity 加权的 empirical distribution；
  - RFF-MMD 直接计算 `weighted_mean(psi(rows))`，不物理复制 latent 行。
- cross-kNN / missing mass：
  - 先在原始 unique reservoir 上一次性计算 neighbor geometry 和每个 row 的 statistic / missing indicator；
  - reference corpus 永远不物理复制；
  - bootstrap mean = 以 query 侧 hanchan multiplicity 加权的 row statistic 均值；
  - symmetric metric 再把两个方向按 `0.5` 合并。
- 对每个 metric family 计算：
  - `d_m(M0,D1)`、`d_m(M0,D3)`、`d_m(D1,D2)`；
  - `delta1_m = d_m(M0,D1) - d_m(D1,D2)`；
  - `delta3_m = d_m(M0,D3) - d_m(D1,D2)`。
- CI 取 2.5th / 97.5th percentile。

## 四态判定规则（运行前冻结）

### `latent_coverage_signal`

必须同时满足：

1. 在 4 个 metric families 中，至少 3 个同时满足：
   `delta1_m CI lower > 0` **且** `delta3_m CI lower > 0`。
2. M0-specific latent support 双向成立：对 D1 和 D3 都满足
   `missing_mass(M0→D) - missing_mass(D→M0)` 的 bootstrap CI lower `> 0`。

不要求某个绝对 distance 数值。

### `latent_credit_ambiguity_signal`

定义：

- 对每个 route 的 canonical reservoir，`k=16` 同 route 最近邻，**排除 self 与相同 `canonical_hanchan_hash` 的全部行**；
- `H_global`：该 reservoir target 的经验熵（nats）；
- `H_local`：每个邻域内 target 经验熵的均值；
- `U_obs = 1 - H_local / H_global`。

Null calibration：

- 对每个 route，保持 latent 结构与 kNN 图完全不动，**以 hanchan 为 cluster permutation target**：同一个 hanchan 的 3 个 reservoir rows 共同换 target。
- 999 次 permutation，`permutation_seed=20260818`。
- **D1 与 D2 是同一批 6000 underlying hanchans，必须使用同一个 shared hanchan permutation index**（按 `canonical_hanchan_hash` 对齐）；M0 与 D3 各自独立 permutation。
- 得到 `H_local_null` 与 `U_null`。
- `p_predict = (1 + count(U_null >= U_obs)) / 1000`。
- route 级 `credit_ambiguity_vote = true` 当且仅当 `p_predict > 0.05`。
- 报告措辞必须写成 **shuffle-like ambiguity / no detectable local predictability**，不得写成“证明 target 与 latent 独立”。
- `latent_credit_ambiguity_signal = true` 当且仅当：
  `M0 vote = true` **且** `D3 vote = true` **且** `(D1 vote = true OR D2 vote = true)`。

该 signal 只表示“值得做 controlled credit-assignment experiment”，不表示 `final_rank_mc` 已被证明为根因。
