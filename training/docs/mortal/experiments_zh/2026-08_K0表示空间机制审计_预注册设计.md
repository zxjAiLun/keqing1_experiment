## 固定降维与存储

- `phi_dim = 1024`。
- 固定随机投影 `P ∈ R^{256×1024}`：`torch.Generator(seed=20260815)`，标准正态生成后每行 L2 归一化；保存矩阵与 SHA-256。
- 存储前对投影 `z = P @ phi` 做 L2 归一化；距离默认使用 `cosine_distance = 1 - dot(z_a, z_b)`。
- canonical reservoir：每 route 每 hanchan 固定取 3 行，行号 `floor(j * n / 3)`，`j=0,1,2`，`n` 为该 hanchan loader row 数。共 `4×6000×3=72000` 条。
- 每个 reservoir 行保存：`route, file_index, target, z`；D3 额外保存 event category（普通行记 `ordinary`）。
- D3 event row 全集：对 v2 gate-F 的 151,282 个 exactly-once mapped rows，保存 `category ∈ {explored, hash_rejected, budget_exhausted}`、`file_index`、`target`、`z`。普通 D3 行使用 canonical reservoir。
- D3 exploration downstream：对每个 `explored` 行，保存同 hanchan 内紧接着的最多 8 条 loader row 的 `z` 与 target；不足 8 条按实际条数。下游样本只做描述性密度/距离，不参与四态投票。
- exposure reservoir：每 route × seed 从 v2 `training_exposure.json` 的 `consumed_per_file` 权重做固定 seed 的加权采样，N=18000；只用于第四组描述性比较，不参与四态投票。

## 冻结距离指标

四个 metric families 均先在固定投影、L2 归一化空间计算：

1. `sliced_wasserstein`：256 个固定投影方向，`direction_seed=20260816`；每方向按 4096 个均匀分位数计算 1-Wasserstein。
2. `rbf_mmd`：`k(x,y)=exp(-d_cos^2 / (2 * sigma^2))`；`sigma` 固定为四个 canonical reservoir 合并后 within-route pairwise cosine distance 中位数的平方根；若中位数为 0，fallback `sigma=0.1`。该 `sigma` 必须在 bootstrap 与最终判定前写入报告并冻结。
3. `cross_knn_distance`：`k=16`；同时报告 `A→B` 与 `B→A`，投票使用两者均值。
4. `latent_missing_mass`：对 route A 的每条 reservoir 行，若 B 中 `k=16` 最近邻平均距离大于 B 自身 `k=16` 最近邻距离的 95th percentile，则记为 missing；`missing_mass(A→B)=missing_count/|A|`。

## 冻结 bootstrap 协议

- `B = 1000`，`bootstrap_seed = 20260817`。
- 每次 replicate：从 6000 个 hanchan 中 **with replacement** 抽 6000 个，取被抽中 hanchan 在 canonical reservoir 中的全部 3 行，形成 bootstrap corpus。
- 对每个 metric family 计算：
  - `d_m(M0,D1)`、`d_m(M0,D3)`、`d_m(D1,D2)`；
  - `delta1_m = d_m(M0,D1) - d_m(D1,D2)`；
  - `delta3_m = d_m(M0,D3) - d_m(D1,D2)`。
- CI 取 2.5th / 97.5th percentile。

## 四态判定规则（运行前冻结）

### `latent_coverage_signal`

必须同时满足：

1. 在 4 个 metric families 中，至少 3 个同时满足：
   `delta1_m CI lower > 0` **且** `delta3_m CI lower > 0`。
2. M0-specific latent support 双向成立：对 D1 和 D3 都满足
   `missing_mass(M0→D) - missing_mass(D→M0)` 的 bootstrap CI lower `> 0`。

不要求某个绝对 distance 数值。

### `latent_credit_ambiguity_signal`

定义：

- 对每个 route 的 canonical reservoir，`k=16` 同 route 最近邻；
- `H_global`：该 reservoir target 的经验熵（nats）；
- `H_local`：每个邻域内 target 经验熵的均值；
- `U_obs = 1 - H_local / H_global`。

Null calibration：

- 对每个 route，保持 latent 结构与 kNN 图完全不动，将 target 在 reservoir 内 permutation 999 次；`permutation_seed=20260818`。
- 得到 `H_local_null` 与 `U_null`。
- route 级 `credit_ambiguity_vote = true` 当且仅当：
  `mean(U_null <= U_obs) >= 0.95`
  即观察到的局部 target uncertainty 下降不显著优于 target-shuffle null。
- `latent_credit_ambiguity_signal = true` 当且仅当：
  M0 的 `credit_ambiguity_vote=true`，且 D1/D2/D3 中至少 2 个为 true。

该 signal 只表示“值得做 controlled credit-assignment experiment”，不表示 `final_rank_mc` 已被证明为根因。

## 下一实验决策边界（audit 通过后才允许讨论）

- `latent_coverage_signal`：只允许进入 M0-anchored targeted augmentation 设计。
- `latent_credit_ambiguity_signal`：只允许进入单一 credit-assignment experiment 设计；corpus、view、optimizer、steps、evaluation 全部冻结，只改 target/credit mechanism。
- `both_signals`：只允许先做最小 2×2 factorial 的预注册设计。
- `inconclusive`：停止 observational audit，直接设计最小 controlled factorial。
