## 研究解释

正式结果支持的是：

> 在冻结 K0 表示和冻结 `behavior_action_mc + CQL` objective 下，M0 与 D1/D3 的训练信号组成存在可重复的 Q-output gradient distribution shift，且超过 D1/D2 pipeline/view gap。

更具体的机制名称建议：

```text
value–CQL / centered-preference gradient geometry shift
```

而不是泛泛的 `gradient shift`。

本次结果**不支持**以下方向作为已确认主机制：

- latent state coverage augmentation
- 简单 action-diversity / coverage 补数据
- reward / credit proxy redesign
- route-specific preserved-Adam mismatch

本结果**不证明**：

- CQL 本身是坏的
- `cql_weight=0` 会更强
- 删除或大改 CQL 会直接修复 D1/D3

它支持的是一个 `corpus type × CQL/value objective interaction` 假说，下一步如需因果验证，应另开严格 prereg 的 interaction experiment，不做 loss/objective grid fishing。
