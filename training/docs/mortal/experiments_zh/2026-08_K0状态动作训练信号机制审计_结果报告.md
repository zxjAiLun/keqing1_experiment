## 研究解释

正式结果支持的是：

> 在冻结 K0 表示和冻结 `behavior_action_mc + CQL` objective 下，M0 与 D1/D3 的训练信号组成存在可重复的 Q-output gradient distribution shift，且超过 D1/D2 pipeline/view gap。

更具体的机制名称建议：

```text
value–CQL / centered-preference gradient geometry shift
```

而不是泛泛的 `gradient shift`。

### 关键机制线索

1. **G2/G3 同时阳性，且不是擦线通过**
   - G2 测 value 与 CQL 的相互关系；
   - G3 测 CQL 在 legal actions 之间的 centered preference pressure；
   - 两者都显示 M0 与 D1/D3 存在稳定差异，说明变化集中在 objective 内部 component 的 interaction geometry，而不是单纯总 gradient 方向。

2. **G1 未过让机制更具体**
   - G1 的总 Q-gradient direction 未达到冻结门槛；
   - 说明不是“所有训练梯度整体大幅转向”，而是 objective 内部 components 的耦合方式改变。

3. **Behavior agreement 提供 descriptive 线索**
   ```text
   M0  0.8901
   D1  0.9998
   D2  0.9073
   D3  0.9727
   ```
   D1/D3 更接近 K0 自身 policy；CQL preference 在这些高度 K0-greedy corpus 上更像在强化已有 preference structure，与 final-rank MC value correction 的几何关系因而不同于 M0。

4. **Adam DQN/CQL parameter cosine 是独立 cross-check**
   ```text
   brain parameter-gradient cosine:
   M0  +0.1452
   D1  -0.0311
   D2  -0.0349
   D3  -0.0319
   ```
   虽然 descriptive only，但与正式阳性的 G2 方向一致，支持 “objective interaction shift” 的解释。

### 本结果不支持的方向

- latent state coverage augmentation
- 简单 action-diversity / coverage 补数据
- reward / credit proxy redesign
- route-specific preserved-Adam mismatch

### 本结果不证明

- CQL 本身是坏的
- `cql_weight=0` 会更强
- 删除或大改 CQL 会直接修复 D1/D3
- generated corpus 与 objective interaction 是 D1/D3 负收益的唯一因果原因

它支持的是：

```text
corpus type × CQL/value objective interaction
```

下一步如需因果验证，应另开严格 prereg 的 interaction experiment，不做 loss/objective grid fishing。

## 最终研究结论

一句话版本：

> M0 相对 D1/D3 的优势，目前没有得到“局部状态动作覆盖不足”解释的机器支持；反而获得了明确的 objective-gradient mechanism signal：generated/K0-like corpora 上，final-rank value 与 CQL preference 的相互作用及 centered preference pressure 与 M0 显著不同，且该差异超过 D1/D2 pipeline view gap。

研究方向应从“继续制造更好的 generated corpus”转向：

> 验证 generated corpus × current CQL/value objective 是否存在导致性能下降的因果 interaction。

但当前不训练、不生成，先保持本审计 closure。
