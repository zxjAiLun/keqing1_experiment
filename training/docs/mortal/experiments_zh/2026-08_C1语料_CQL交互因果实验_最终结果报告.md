## 2. Hypothesis and causal question

C1 的 primary causal question 是：

> 对固定的 `K0@70k` legacy continuation contract，D1 相对 M0 的 continuation penalty 是否依赖当前 CQL preference contribution？

这里检验的是 `corpus type × objective intervention` 的 interaction，而不是总体比较“CQL=0 是否更强”。primary corpus factors 为：

- `M0_operational_control`：mixed replay operational control；
- `D1_project_owned_k0_view`：project-owned K0-view 数据路线。

## 4. Estimand and data lineage

对每个 matched training seed `s` 和 evaluation hanchan identity `h`：

```text
d_current[s,h] = Pt(D1_CURRENT, s, h) - Pt(M0_CURRENT, s, h)
d_off[s,h]     = Pt(D1_CQL_OFF, s, h) - Pt(M0_CQL_OFF, s, h)

interaction_row[s,h] = d_off[s,h] - d_current[s,h]
interaction_seed[s]  = mean_h interaction_row[s,h]
I                    = mean_s interaction_seed[s]
```

## 8. Limitations and decision boundary

C1 不证明以下命题：

- CQL 在所有 corpus、任务或训练阶段都不好；
- D1 的绝对强度高于 M0；
- D1 数据质量更高，或 D1 的全部 underperformance 都由 CQL 单独造成；
- `cql_weight=0` 已成为新的 operational recipe；
- CQL 应永久删除，或应直接采用其它 weight；
- CQL_OFF checkpoint 自动晋级 K1 或 model pool。

这项结果测量的是 `语料路线 × CQL intervention` interaction，不是 D1 与 M0 的 absolute-strength comparison。只有在新的 preregistered confirmation experiment 中，recipe promotion 才能被单独检验。下一步若研究 interaction 来源，应围绕 state-action distribution、target calibration、policy entropy、Q overestimation 或 generated-corpus bias 设计新的 experiment ID；当前不扩大 D1 数据量、不直接训练 K1、不直接推广 CQL_OFF。
