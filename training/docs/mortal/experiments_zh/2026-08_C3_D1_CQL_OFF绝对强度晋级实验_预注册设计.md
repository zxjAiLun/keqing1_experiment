# C3 D1_CQL_OFF 绝对强度晋级确认实验：预注册设计

> 实验状态：**预注册冻结（FROZEN v1）；仅包含只读评测与判定设计；不训练新模型，不生成新 checkpoint。**

## 1. 实验身份与研究目的

- **实验 ID**: `C3_d1_cql_off_absolute_promotion_2026_08`
- **前序依赖**: `C1_corpus_cql_interaction_2026_08`（确认 DID causal interaction +11.550 Pt/半庄）

  2. 正式 operational continuation control **`M0_CURRENT`**

## 2. 严格禁止事项

- **禁止训练或修改任何 checkpoint**：严格复用 C1 已归档的 3 个 `D1_CQL_OFF` checkpoints 与已有的 baseline checkpoints。
- **禁止复用 C1 evaluation logs**：评测必须在全新的对局 ID 区间（1900000..1920999）进行，不得与 C1 有任何局级重叠。
- **禁止根据中途结果修改参数或事后挑选最佳 seed**：预先指定 `20260807` 为 canonical checkpoint。
- **禁止自动 resume 或覆盖已有输出**。

## 5. 统计口径与晋级规则

在每个 seed 的每个同桌半庄中，定义两组配对差值：

$$x = \text{Pt}(\text{D1\_CQL\_OFF}) - \text{Pt}(\text{K0\_70k})$$
$$y = \text{Pt}(\text{D1\_CQL\_OFF}) - \text{Pt}(\text{M0\_CURRENT})$$

分别计算 3 个 training seed 均值及等权重 equal-seed 均值。

### Bootstrap 协议
- **抽样方法**: Equal-seed hierarchical paired bootstrap（$x$ 和 $y$ 在每个 seed 内共享相同的半庄重抽样索引）
- **Reps**: 5000
- **Seed**: 20260826
- **置信区间**: 95%

### 判定逻辑
必须**同时**满足以下全部条件：
1. **$x$ vs 70k**:
   - 3/3 seed means > 0
   - Hierarchical CI95 下限 > 0
2. **$y$ vs M0_CURRENT**:
   - 3/3 seed means > 0
   - Hierarchical CI95 下限 > 0
3. **Hard Gates**: Checkpoints SHA 严格匹配，全部 12 shards (3,000 logs) 解析完整。
