## 1. 实验定位与预注册假设

F1 是 targeted high-signal decision filtering 路线的第一个实验。核心问题：M0 中只有约 11% 的行为决策与 K0 greedy action 不一致，uniform replay 是否稀释了这些真正能改变 action preference 的训练行？

预注册假设：若 disagreement-priority 采样具有真实强度收益，则：

- Primary（PriorityVariant − R2 Control）3/3 seed 均值为正且 crossed-bootstrap CI95 下界 > 0；
- Absolute（PriorityVariant − K0_70k）同样满足。

两式同时满足判定 `promotion_supported`；仅 Primary 满足判定 `sampling_effect_only`；否则 `not_supported`；任一 gate 失败为 `invalid`（fail-closed，不出裁决）。

## 4. 科学结论（证据边界）

1. **本实验证明的是：50% disagreement-priority、带放回重采样这一具体协议在当前 400-step continuation 设置下显著有害。** Primary 与 Absolute 均 3/3 负向且两个 CI95 的上界均低于零，统计上方向一致、幅度可观。
2. **不能由此断言：** 重复采样机制本身、off-policy 分布偏移、或 disagreement 优先思想整体已被证明有害。约 78% 的 priority duplicate rate 只是当前最合理的机制假设，本实验未做机制归因，也不能区分「重采样重复」与「分布偏移」两个候选解释。
3. **与 S1 的对照是描述性观察**：S1（不动采样，只加辅助头）Primary 3/3 正向；F1（动采样）3/3 负向。两者不是同一对照下的受控比较，不构成对任何机制的因果推断。
4. **high_signal 判定本身工作正常**：三 seed hs 率 ~11% 与 M0 先验吻合，scorer bit-exact，无 gate 失败。被否证的是采样协议，不是判定机制。

## 5. 终止事项（停止规则）

- 不重跑 F1，不调整 priority 比例后沿用 F1 身份；
- 不做 25%/75% 优先级比例 sweep；
- 不挑选 seed、不追加对局、不晋级任何 checkpoint；
- 后续 disagreement 路线研究必须建立新的 preregistered experiment ID（F2 已按此规则建立）。

## 6. 后续路线

F2（`F2_disagreement_weighting_without_resampling_pilot_2026_09`）在同一 disagreement 判定与同一 base stream 上，改为**无重采样的温和加权**：每批 512 行全部使用一次，disagreement 行 loss 权重 2.0、其余 1.0，按 batch 权重和归一化，同一权重应用于逐行 value/CQL/next-rank loss。F2 为 adaptive pilot，无论结果如何都不直接晋升 K1。
