## 3. 共同 Estimand

所有 12 个 checkpoint 在同一批 12000 shared rows 上进行评分。

对任意指标 $m$：
$$
\Delta_R(m) = m(R, \text{CQL\_OFF}) - m(R, \text{CURRENT})
$$
$$
I(m) = \Delta_{D1}(m) - \Delta_{M0}(m)
$$

主结果使用 M0/D1 panel 各 50% 权重的 balanced shared panel。

## 4. 两大机制 Family 与判定标准

### 4.1 Q Calibration Family
逐 row 计算：
- $q_{\text{behavior}}$
- $\text{residual} = q_{\text{behavior}} - \text{target}$
- $\text{abs\_residual} = |\text{residual}|$
- $\text{overestimate} = \mathbf{1}[\text{residual} > 0]$

`q_calibration_signal` 成立充分必要条件：
1. 3 个 training seed 的 $I(\text{abs\_residual}) < 0$；
2. $I(\text{abs\_residual})$ hierarchical CI95 upper bound $< 0$；
3. 3 个 training seed 的 $I(\text{overestimate\_rate}) < 0$；
4. $I(\text{overestimate\_rate})$ hierarchical CI95 upper bound $< 0$。

### 4.2 Parameter-Gradient Family
对每个 route panel（M0 / D1 各 6000 rows）按 frozen hanchan identity 排序，分成 60 个固定 microbatch（每 batch 100 rows）。
对每个 checkpoint / microbatch：
- $L_{\text{value}} = 0.5 \cdot \text{mean}((Q_{\text{behavior}} - \text{target})^2)$
- $L_{\text{cql}} = \text{mean}(\text{logsumexp}(Q_{\text{legal}}) - Q_{\text{behavior}})$
- $g_{\text{value}} = \nabla_{\theta} L_{\text{value}}$
- $g_{\text{cql}} = \nabla_{\theta} L_{\text{cql}}$
（参数范围 $\theta$：Brain + DQN 中同时被两种 loss 触达的全部共享参数；0 optimizer steps）

逐 batch 计算参数余弦相似度及冲突：
- $\text{gradient\_cosine} = \cos(g_{\text{value}}, g_{\text{cql}})$
- $\text{gradient\_conflict} = \mathbf{1}[\text{gradient\_cosine} < 0]$

`parameter_gradient_conflict_signal` 成立充分必要条件：
1. 3 个 training seed 的 $I(\text{gradient\_cosine}) > 0$；
2. $I(\text{gradient\_cosine})$ CI95 lower bound $> 0$；
3. 3 个 training seed 的 $I(\text{gradient\_conflict\_rate}) < 0$；
4. $I(\text{gradient\_conflict\_rate})$ CI95 upper bound $< 0$。

## 5. 统计与 Machine Verdict 规则

- **Bootstrap**: reps = 5000, seed = 20260824, 95% CI, 3 training seeds 等权。
- **Q Metrics Bootstrap 单位**: source hanchan。
- **Gradient Metrics Bootstrap 单位**: 固定 microbatch。
- **Verdict 映射**:
  - calibration = true, gradient = false $\to$ `q_calibration_signal`
  - calibration = false, gradient = true $\to$ `parameter_gradient_conflict_signal`
  - calibration = true, gradient = true $\to$ `calibration_and_gradient_signal`
  - 两者均 false $\to$ `inconclusive`
  - 任一 gate 失败 $\to$ `no_verdict_gates_failed`
