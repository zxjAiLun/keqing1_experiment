# P4-M12：从 U32 续训 32 轮，用父子实战比较决定下一笔预算

**这是本轮的唯一入口。** 冻结于执行之前（design-only），执行记录与结果回填到本文。

## 1. 来源与授权（负责人 2026-09-15 裁定）

- **不批准**上一轮的"梯度噪声探针"；上一轮那份 gap probe（学习曲线 / 参数增量 / 收益均值噪声）
  **不进入下一轮决策依据**，其扩展**到此为止**。
- 已确认**超过 K0 的 U32**；下一笔预算的问题是"**这条训练线能否在 U32 之上继续产生收益**"。
- U32 的天梯接入由 Workbench agent 负责，**不在本实验范围**。上天梯不等于已超过 external。
- 本实验：**U32 → 再做 32 个 cycle → 固定端点 → 与 U32 直接比较**。

被裁定方指出的上一轮错误（记录在案，避免重犯）：曲线缺少流局/立直扣点结算与正式同分排序；
分段斜率未走 `slope_ci()`，且该函数破坏了轮次对应；`2.623−2.459=0.164` 而非报告里的 `0.123`；
"长滞后余弦归零 ⇒ 没有学习信号"不成立（不同轮次策略与访问状态在变、Adam 逐坐标预条件、
32 个增量在滞后 30 只有约两对观测）；`SE(mean G)/|mean G|` 不是策略梯度噪声；
**Gate A 的通过不能被重新解释为"随机游走碰巧有利"，它仍是有效的模型对战证据。**

"只有身份与种子变了"是**被检查的性质**，不是文档里的说法：
`training/mortal/p4m12_direct_pg.py` 的 `assert_only_identity_changed()` 在 import 时校验
"变化的键集合恰等于声明的 13 个"，并对 lr / loss / 对手 / 裁剪这类继承块做双向断言（漏改与误改都会拒绝）。

**预算**：32 cycles × 256 半庄 = **8,192 半庄**，固定，**不根据中间曲线自动延长**。
中间 checkpoint 正常保存，但**不挑"看起来最好"的读点**。

## 4. 评测安排

**第一关 Gate C：候选对父模型（U64 vs U32），不是再次对 K0。**

- 冻结协议：原生 `one_vs_three_native.py`，双向各 **1,024 半庄**
  （`--seeds 256 --seed-start 742000 --seed-key 8192 --batch-seeds 8`），
  候选先做 solo、再做 mirror（角色对调、同种子）。
- 评测种子块 **742000–742255**，与训练种子（733000–735047）及 P4-M11 全部分区不相交。
- 裁决：`adjudicate_ovt_gate.py`，指标与阈值沿用既有冻结口径
  （`G=(S−O/3)/2`，`--threshold 2.0`）。
- **通过条件（沿用既有标准）**：两方向候选收益均为正、G 的 95% 区间下界 > 0、G 均值 ≥ +2。
- 完整结束后裁决；**不加局、不换中间 checkpoint**。

**通过后**才跑同预算的 Gate D（U64 vs external，种子块 743000–743255），判断是否接近/越过 EVE 门。
**未通过**则保留 U32 为当前交付模型，结束这次续训，**不自动再加 32 轮**。

## 5. 执行上不再重复旧问题

- **不新增**内存 gate / watchdog / 资源探针；沿用 P4-M11 同规模路径（阈值仍为"只记录不中止"）。
- 直接复用已验证的采集、累积更新、reconciler、recompute gate 与父恢复校验。
- 跑前先做 `--dry-run`：验证身份、父恢复、Adam step 与种子派生，再真跑。
- 同一目录内报告与评测有统一入口（本文 + `RESULT.md`）。
- 磁盘：启动时实测 E 盘 311.8 GiB 空闲；32 轮体量与上轮同量级。

## 6. 复现入口

```bash
# 冻结配置自检 + 身份/恢复验证（不采集、不训练）
python -m training.mortal.p4m12_direct_pg --output-dir <scratch> --dry-run
# 正式续训（32 轮 × 256 半庄）
python -m training.mortal.p4m12_direct_pg --output-dir artifacts/experiments/student_policy_v1/P4-M12_direct_pg_U32_plus32
# Gate C
python training/mortal/one_vs_three_native.py --challenger "p4m12_u64=…U64_eval_weights.pth" \
  --champion "p4m11_u32=…U32_eval_weights.pth" --output-dir artifacts/eval/ovt_p4m12_gateC_solo \
  --seeds 256 --seed-start 742000 --seed-key 8192 --batch-seeds 8 --require-cuda --device cuda
python training/mortal/adjudicate_ovt_gate.py --solo-metrics …gateC_solo/metrics.json \
  --mirror-metrics …gateC_mirror/metrics.json --gate-name parent_gain \
  --candidate-label p4m12_u64 --reference-label p4m11_u32 --expect-seed-start 742000 \
  --threshold 2.0 --output artifacts/eval/p4m12_gateC_verdict.json
```
