# 现成语料与早期路线复盘：主线改向

日期：2026-09-07。研究分析，不是已执行的新训练。此文取代同日两份早期建议中的“先找新天凤 CSV / 重建 K0 再推进”优先级；不改写历史实验裁决。

## 结论

已有语料足以启动新的训练工程，缺人类牌谱不是当前阻塞。也不能说合成牌谱从零训练、在线刷新、teacher transfer 尚未试过。当前更值得改变的是训练目标与知识来源，而不是再次给 K0 加一个小扰动。

建议下一主线为 **Mortal-native 的独立策略学生：现成状态 + 本地 external 重新标注 + 纯策略训练，随后补学生自身访问状态**。这是工程路线建议，不保证达到 external，更不保证超越它；必须明确继承 external 的知识，不包装为无教师自主强化学习。

## 3. 本轮最重要的代码发现：旧 teacher CE 与行为 CQL 重复

旧仓库 `29b3a6a^:scripts/run_mortal_dqn_offline.py`：

- 第 508 行：`cql_loss = q_out.logsumexp(-1).mean() - q.mean()`。
- 第 520 行：`teacher_ce_loss = ce(q_out, actions)`，其中 `ce` 为默认 `nn.CrossEntropyLoss()`。
- 第 522 行：将两者都加到 MC 回归与 next-rank 辅助损失上。
- `prepare_teacher_replay_transfer.py` 只筛 external challenger 牌谱动作，没有在训练时加载 external 为其他玩家的状态重新预测。

因此，对相同的合法动作 logits 与牌谱动作，**CQL 项 = hard-label CE 项**。这里是具体实现的代数恒等式，不是在声称所有 CQL 算法等同于行为克隆。

在 `cql.min_q_weight=5` 的配方下，旧 T1 的 `teacher.ce_weight=0.1` 使总行为偏好系数由 5 变成 5.1；它没有独立的教师分布、教师替代动作标签或新的价值目标。T2 风险门只削弱额外 CE；同一高风险行原有 CQL 模仿仍然存在。不能把它描述为关闭了该行的全部行为模仿。

本轮使用现有 Windows Python，在 8×46 随机合法动作张量上验证：loss 差 `4.44e-16`，梯度最大差 `1.39e-17`。这只验证数学关系，不证明这些实验失败的全部因果，也不为再次扫 CQL 系数提供理由。

另一条更早的真实 teacher-score 蒸馏也不能遗漏：`archive-keqingrl-mortal-imitation-202605:docs/mortal_action_contract.md` 记录的是 **Mortal→KeqingRL 的跨动作体系适配**，包括红五合并、reach+discard 组合、top-K 支持与动作机会覆盖。它与原生 46 动作空间的完整策略学生不同；不能说项目从未尝试 soft teacher，但也不能将其结论直接覆盖新的原生学生。

## 4. 问题本质：多数实验没有增加新的决策指导

现行主损失仍同时拟合行为动作的实际回报、偏好行为动作、预测下一顺位。已有结果支持停止继续在这个局部范围密集微调，不支持宣布某一个系数、运气噪声或模型容量是唯一病因。

关键区别是：

- external 生成全桌牌谱，让学生拟合其行为与这场结果；
- external 在任意已有状态上重新回答“我此时会怎么选”，学生直接学习这个答案。

后者可以利用弱模型牌谱中的状态，同时不把弱模型选过的动作当正标签。它不需要人工认定放铳就是错，也不需要把单次输赢转成逐手惩罚。训练目标将从嘈杂的结局推断，转为可直接拟合的本地教师决策；这是提高目标可学习性的工程选择，不是声称教师完美。

## 5. 建议的单一主线：先把已知强策略学出来

1. **数据直接复用现有资产。** S0 外部自对战提供起点，混战/D3 提供其他状态。牌谱按比赛身份划分开发与保留数据；不再建设一套大型审计平台。不要整包训练旧评测后继续声称对旧测试独立。
2. **全视角状态，不等于全视角照抄动作。** 对其他模型的决策状态，用本地 external 原生编码、合法 mask、46 动作重新标注。只给教师当前玩家可见的信息；杠选择等独立决策使用其真实原生编码。首次实现用教师 greedy 动作监督即可，不同时引入 Q 标度/温度网格。
3. **随机初始化一个 Mortal-native 策略学生，独立训练。** 不继承 K0 权重或 Adam；不重建 KeqingRL 跨空间适配。此阶段只优化合法动作策略损失，不同时加入 MC、GRP、next-rank、分数头或 K0 锚定。网络容量/批量按现有 GPU 吞吐定一个配置，不能把 70K 当神奇步数或从零模型的第 400 步当终局。
4. **把训练曲线与实战分开。** 用保留状态上的 teacher agreement/CE 看是否学得会，用少量预定读点观察完整策略成长；末端候选再接受机器强度评测。报告对固定 K0 与固定 external 的差距，不能用弱模型混战池的 2.4x 作为追平证据。只需完整日志与独立测试等必要约束，不要求每次小改动三 seed 科学裁决。
5. **若离线拟合好、实战差，直接补学生状态的教师指导。** 学生自己对战，external 对学生真正访问的状态给标签，再继续同一个学生。这是预先设计的状态分布闭环，不是输了以后无限扫参数；停止预算应由实际吞吐和曲线确定，不捏造目前尚未测得的耗时。

这条路线的第一成果是“可训练、接近已知强教师的学生”，不是超越 external。若目标是超越教师，则之后还需要策略改进来源；已有 P2/P3 单步反事实不足以直接承诺这一步成功。反过来，如果纯策略学生连独立状态上的教师决策都拟合不好，先解决表示/容量/优化问题，不能立刻叠强化学习损失掩盖它。

方法依据：[Policy Distillation](https://arxiv.org/abs/1511.06295) 将 DQN 教师策略迁移给学生；[DAgger 原论文](https://proceedings.mlr.press/v15/ross11a.html) 讨论对学生诱导状态分布进行教师标注。论文不是本项目强度保证；本文具体选用 hard greedy 标签作为第一版简化方案。
